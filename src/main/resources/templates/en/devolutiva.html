The result of the whole study

The study gathered 2 pairs. The analysis declared before the collection — the Wilcoxon test over the difference of each pair — gave p = 0.25.

That value is below 0.05, the declared limit: the readings matched the targets more than chance would explain easily. It is a statement about the test, not about the origin of the information, and the protocol has declared limits — for instance, it does not distinguish communication with the person who died from other explanations.

That value is not below 0.05, the declared limit: taken as a whole, the readings did not match the targets more than chance explains. A result like this does not prove that the phenomenon does not exist; it says that this study did not detect it.
